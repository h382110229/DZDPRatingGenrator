# Hawkの大众点评评价生成器 v2.0.1

> 原生 Android 版本，基于 Kotlin + Jetpack Compose 重写

## ⚠️ 重要提醒

**本版本与原 React Native 版本 (v1.x) 签名不同，无法覆盖安装。**

升级前请：
1. 备份旧版中的 AI 供应商配置和自定义设置
2. 卸载旧版 App
3. 安装新版 v2.0.1
4. 重新配置供应商信息

---

## 功能特性

- ✨ AI 智能生成评价文案（多种风格）
- 📍 高德地图定位支持
- 🖼️ 上传图片生成评价
- 🎤 语音输入
- 📋 复制/分享生成结果
- 🌙 深色主题 + 金色高亮

## 技术栈

- Kotlin + Jetpack Compose
- Hilt 依赖注入
- Retrofit + OkHttp
- Coil 图片加载
- DataStore 持久化
- AndroidX Navigation

## 构建要求

- Android Studio Ladybug 或更高版本
- JDK 17
- Android SDK 35
- Gradle 8.11.1
